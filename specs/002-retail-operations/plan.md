# 经营流程实施计划

1. 修复网页耐久请求、首次盘点、草稿恢复并将原三项红色验收转绿；补存储失败、并发和冲突测试。
2. 新增配置、单据和索引迁移；保留旧金额/货币快照，配置确认后才用于新活动。
3. 抽取销售准备/过账、退货授权/过账的事务内用例，独立换货在单一事务内复用，不跨 HTTP 拼接半完成交易。
4. 实现在途调拨、损坏处置、交班核对、延期申请审批、账号恢复、资料更正、云端草稿和完整待办。
5. 网页与小程序共享后端授权和状态合同；新模块提供可操作表单、明细、列表、加载/错误/冲突/待核对状态。
6. 真实 MariaDB 新建/升级与全流程、并发、权限、金额、对账；30 并发负载及 500 商品/10 活动/目标销售数据量测试；浏览器端到端。
7. 更新 OpenAPI、数据模型图、SRS/SDD/STD、流程说明和证据；独立分支 GitHub PR、完整源码及导入包。

容量测量要报告实际硬件、数据量、P95 和错误率；本机结果不推定未购买云机表现。代码交付完成后，账号与目标部署门禁另行完成。
