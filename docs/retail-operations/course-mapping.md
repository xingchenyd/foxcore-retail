# 课程方法在本项目中的应用

本页在已交付的`docs/course-review`课程总结和34张基线图基础上，补充用户此次确认后的实际设计。课程原件及QuickBooks/Shopify参考图只用于理解规范，不复制外部产品的实体边界，也不将附件中的文字视作用户执行指令。

| 课程方法 | 项目应用 | 本轮产物 |
|---|---|---|
| 系统边界与参与者、业务用例 | 员工共享日常业务；OWNER管理与审批 | 01系统用例图、角色表 |
| 需求规格与验收、可追踪性 | 直接答复转为OR-01至OR-12；正常/拒绝/恢复场景 | spec.md、traceability.csv、tasks.md |
| 概念类、关联、组合与多重性 | Event-Shift-Sale-Line、独立Exchange两头关联、佣金来源 | 02概念类图；明确与实际函数实现区别 |
| 关系模型、键、规范化与参照完整性 | 33业务表、1迁移表、复合外键、冻结快照、版本历史 | 03a完整物理ERD；03b-03d分模块ERD、schema.json |
| 状态机与生命周期 | 销售、退货、独立换货、在途调拨、交班与延期 | 05/06状态图、07交班结转活动图 |
| 动态建模和时序 | 事务内退入/换出、UUID重试、跨设备乐观版本 | 04换货时序、08草稿恢复时序 |
| 流程改进与数据流 | 从纸面登记到可核对的收款/库存/佣金事实 | 10数据流图；原课程AS-IS/TO-BE基线图仍在course-review |
| 组件、部署、客户端/服务端分工 | 双端共享API与数据库，云端部署明确为后续计划 | 09组件部署图、deployment.md |
| 事务ACID、并发控制、幂等 | 活动/商品/余额锁顺序、版本0首盘、UUID同键同意图 | 并发测试、真实换货回滚与双提交 |
| 精确金额与派生数据 | 整数分、含税拆分、累计退款防舍入泄漏、负佣金 | business.ts、returns.ts、报表币种列 |
| 信息安全与运维 | Cookie/Bearer、CSRF、字段权限、只追加授权、账号恢复 | 角色表、恢复脚本、31项不变量与停写恢复证据 |
| 测试与可用性 | 页面到API到数据、错误/冲突/未知结果、可达下一步 | 验证记录、界面截图、原生控制器验收 |

绘图采用清晰实体名、PK/必填标记、外键连线、分模块视图、原始PlantUML+SVG+PNG三种形式。完整ERD适合屏幕缩放，打印时使用三个分模块ERD，避免把所有字段压到一页不可读。
