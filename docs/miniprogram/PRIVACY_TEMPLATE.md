# 发布前的隐私说明填写草案

本文件用于账号持有人结合真实经营与平台后台填写，不是已生效的隐私政策。方括号必须由运营者确认后替换，不能把示例保存期限当作已经执行的承诺。

## 实际数据与目的

| 数据 | 使用目的 | 处理位置 |
|---|---|---|
| 员工账号、角色与关联员工ID | 身份校验、业务权限、本人数据范围 | 现有后端及数据库；本机缓存当前会话 |
| 员工录入的销售、库存、退货、佣金信息及参考号 | 现场经营、对账、审计 | 与管理网页共用的现有数据库 |
| 会话 token 与 CSRF token | 识别有效会话、保护写操作 | 小程序本机存储；服务端保存会话哈希 |
| 未提交销售草稿与结果待核对的原操作 | 中断恢复、防止重复记账 | 按员工账户分隔的本机存储；主动保存云端的草稿及版本历史在共同后端保存 |
| 全员销售、库存、收货盘点、调拨、退换货与现金交班记录 | 员工协作、资金和商品交接核对 | 经身份校验的员工及管理员共享；佣金只向本人及管理员提供，成本和账号管理只向管理员提供 |

客户端不保存账户口令；输入框中的密码只用于登录或更改口令。当前版本没有获取微信头像昵称、手机号、通讯录、地理位置、相册或摄像头的功能，也没有微信支付与第三方广告/统计SDK。开发适配器不属于发布的小程序包。

2026-10-28版本采用业务账号隔离云端草稿并保留版本历史；业务和审计数据暂不自动删除。员工停用会撤销访问，历史经营记录仍保留。运营者须在正式隐私说明中写明真实留存、查阅、更正与权利请求处理安排，不把“暂不自动删除”解释为免于承担实际适用的个人信息保护义务。网页临时口令待核对记录不含口令原文，未知结果通过服务器核对或安全结束旧请求后重新设置。

## 需要运营者填写

- 运营者：[名称]；联系渠道：[联系地址或邮箱]。
- 服务端部署位置、数据库服务提供方与数据接收方：[按实际部署填写]。
- 业务和审计记录保留期限：[根据实际制度确定]；草稿与会话的清除方法：[注明本机、退出和管理员处理的边界]。
- 员工访问、更正、账号停用和其他请求渠道：[真实联系方式及流程]。
- 小程序后台应声明的数据项与接口：[根据实际版本和平台提示填写；如后续新增扫码、图片、手机号或微信账号绑定，重新核对]。

退出会撤销当前服务端会话并清除本机登录凭证；不会删除业务记录、未核对操作与本机草稿。未核对操作需保留以便原账户重登核对。业务数据更正通过受控单据和审计处理。

正式发布前，账号持有人应确认实际数据流、权限、运营信息、保留与清理行为与说明一致，并按微信后台要求完成相关指引配置。
