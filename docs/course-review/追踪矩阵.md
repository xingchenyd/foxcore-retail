## 从课程产物到实现证据

| 课程部分 | 本轮产物 | 与实现的连接 |
|---|---|---|
| A 业务建模 | 业务用例、现状与改进序列、上下文图、涉众目标 | 线下交接不被省略，系统自动校验与记账职责明确 |
| B 需求 | 系统用例图、五份标准用例规约、权限矩阵、建议质量目标 | 每个主/扩展流有状态、字段、守卫和接口对应 |
| C 分析 | 两张领域类图、13 个系统序列、三组状态图、经营活动图 | 概念职责与当前事务脚本实现分开说明 |
| D 设计 | 九实体概念 ERD、25 表物理总图、六张分域 ERD、字段字典、架构导航 | 从迁移生成键与类型；现有 FK 与应用逻辑约束用不同线型 |
| 质量核验 | 单元、纯函数、HTTP 集成、原生适配验收、浏览器、SQL 不变量 | 不以“有测试文件”替代“本轮已执行”，不混用 Docker/原生验证结论 |

## 角色与操作权限

| 能力 | OWNER | SALESPERSON |
|---|---|---|
| 活动、场地、展位 | 维护与开放/闭场 | 只读 |
| 商品 | 成本/底价/建议价维护 | 只读、成本裁剪 |
| 员工及账号 | 建档、佣金率、账号启停 | 无人员管理权限 |
| 班次 | 排班、取消未开班计划、开关班 | 仅本人开关班 |
| 库存 | 主仓收货、已交接调拨、盘点 | 本展位范围只读 |
| 销售 | 操作全范围 | 仅本人归属 |
| 取消草稿 | 允许 | 仅本人 |
| 取消待收款 CHECKOUT | 原因 + 资金核对 + 商品回收确认 | 不允许，联系管理员 |
| 退货退款 | 授权与登记 | 不允许 |
| 佣金 | 准备、付款、取消准备 | 本人只读 |
| 报表 | 全范围，允许 CSV | 本人范围，裁剪毛利，不允许 CSV |
| 审计 | 允许 | 不允许 |
| 认证 | 登录、改密、退出 | 登录、改密、退出 |

此表根据服务端权限整理。前端隐藏入口提高可用性，真正授权始终在服务端执行。
