# 06 用户操作手册

## 登录与首次设置

打开 [本地系统](http://localhost:3000)。管理员账号为 `owner`。初始密码从本机终端运行 `docker compose exec app cat /run/foxcore-app/owner_initial_password` 获取，首次登录须改为至少 16 字符的个人密码。密码文件在改密成功后删除。请不要把密码粘贴到截图、问题报告或 ZIP 中。管理员可在“人员与班次”发放或停用销售员账号；销售员与员工档案一一关联。

## 日常开场

1. 管理员在“活动与展位”录入场地、活动日期、类别、税率及政策确认，至少建立一个展位后开放活动。
2. 在“商品”录入 SKU、成本和最低成交价；在“人员与班次”建立员工并安排时段。时间输入须包含 UTC 偏移；系统业务日期按多伦多时间计算。
3. 在“库存”先收货入主仓，实物交接后确认调拨到展位。界面可售量是 `在手 − 已占用`。
4. 到班次时间由管理员或该销售员开班。销售员只能操作本人进行中的班次。

## 成交

在“销售工作台”选择班次、商品、数量及与顾客商定的 CAD 单价，保存草稿。点击“准备收款”后系统重新核对底价、活动状态、税率、佣金及展位库存，并占用商品。核对固定应收额，在线下完成收款，再登记现金实收或终端参考号，点击确认成交。系统只记录确认信息，不触发银行卡收费。若确认响应不明，先查询该单并用原请求重试，不要再次向顾客收款。最近单据可用“上一页/下一页”逐页查询。

未成交草稿可取消；处于准备收款状态的单据须先确认付款和商品去向再取消。已成交订单通过退货流程更正，不直接删除。

## 退款、佣金和报表

“退货与核对”仅管理员使用：选择原已成交单和退货行，授权数量及退款额；在线下退款后登记参考号并过账。选择良品时入指定库位；损坏品不入可售库存。超过原销量的累计退货会被拒绝。

“佣金”按销售员查看计提和冲回。管理员准备结算时，系统占用该员工当前所有未结正负流水；在线下付款后登记付款参考。若尚未付款，可取消准备以释放占用。

“报表”按活动、商品或销售员汇总已过账销售，扣除已过账退货；CSV 导出仅管理员可用。毛利估计未计活动费、差旅或工资。操作日志供管理员核对关键写入。发现余额异常时停止新的交易，备份当前卷并执行 `npm run db:check` 排查。

## 常见提示

| 提示 | 处理 |
|---|---|
| 库存不足/已被占用 | 查看展位可售量与待收款单；确认是否需要实物调拨 |
| 商品低于最低价 | 提高商定单价或由管理员调整商品价格规则，重新准备收款 |
| 班次不能开/关 | 检查活动是否开放、当前时间和该班次待处理销售 |
| 幂等键冲突 | 原键只重试相同请求；新动作应重新提交生成新键 |
| 记录已变化 | 刷新页面，重新核对版本、余额和金额后操作 |
