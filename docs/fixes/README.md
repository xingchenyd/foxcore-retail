## 新操作入口

管理员在“活动与展位”使用“完善活动草稿配置”，在“人员与班次”使用“配置员工佣金”；计划班次行提供“取消班次”。过期未开班也可取消，已开始的班次不可用取消替代正常核对。取消原因记录到审计详情。

“库存”支持库位筛选与服务器翻页；盘点下拉框作用于当前库存页，切换页后再选择相应余额。报表可以选活动后按商品汇总；CSV 不限当前页面。普通目录选项通过服务器分页加载至最多 10000 项；超过上限会明确提示，不能将此版本视为大规模搜索选择器的替代品。

退货界面仅呈现 MAIN 或原活动开放展位。界面禁选不是唯一校验，服务端在每个写阶段重新检查。损坏品继续不入可售库存。

## 尚未完成的验收与限制

- 本环境不能安装锁定依赖，只有 Node 22.16.0 / 全局 TypeScript 5.8.3；没有运行 Node 24 的全量类型检查和构建。
- 没有运行 MariaDB、浏览器、Docker、备份恢复。新集成脚本虽已实现，仍可能有运行环境/定位/断言问题需要依据真实结果修正，不可预先算作 PASS。
- `acceptance-69.csv` 中 PARTIAL_COVERAGE 是脚本未完整覆盖该条，不仅仅是环境受阻。例如旧库升级、故障注入回滚、所有生命周期细节、完整新合同字段验证仍需补验。
- PDF/既有 SVG/PNG 派生资料未重新生成。文档同步后明确标为历史派生物；不要把旧 PDF 单独用作新版本权威说明。
- 分批选择器不是跨请求数据库快照；容量/吞吐未做基准；云端 TiDB/Vercel 兼容性未验证。
